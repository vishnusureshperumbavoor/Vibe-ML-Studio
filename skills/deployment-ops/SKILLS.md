# Deployment Ops Skills

**Description:** Technical reference for Hugging Face API and Space provisioning.

## Core Utilities
- **Hugging Face Hub API:** Methods for `upload_folder`, `upload_file`, and `create_repo`.
- **Space Provisioning:** Logic for generating `app.py` and `requirements.txt` for Gradio Spaces.
- **VML Uploader:** The Python logic located in `server/hf_uploader.py`.

## VML-Native Implementation
The Deployment Agent is integrated into the final block of the SFT training notebook for seamless "Arena-to-Cloud" handoff.
