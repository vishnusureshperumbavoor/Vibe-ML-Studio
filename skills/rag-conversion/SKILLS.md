# RAG Conversion Skills

**Description:** Technical reference for Vector Databases (ChromaDB, FAISS) and text embeddings.

## Core Utilities
- **PDF Extraction:** Using `PyMuPDF` or `pdfminer` for clean text retrieval.
- **Semantic Chunking:** Advanced chunking strategies beyond simple character counts.
- **Embedding Models:** Selection of lightweight models (e.g., `BGE-Small`, `all-MiniLM-L6-v2`) for local CPU speed.

## VML-Native Implementation
RAG pipelines in VML Studio utilize the isolated execution kernel for fast data preprocessing.
